# John Snow Cholera Map Redesign 🎨

This project redesigns John Snow’s historic cholera map using modern data visualization principles to improve clarity, readability, and insight while preserving the original analytical intent.

## Objective 🚀
To re-visualize the 1854 Soho cholera outbreak data in a clearer and more interpretable way, demonstrating how thoughtful visual design improves data-driven storytelling and public health insights.

## What Was Done ✍
- Recreated the original John Snow cholera map using modern plotting tools
- Improved visual hierarchy, labeling, and color usage
- Emphasized the relationship between cholera deaths and water pump locations
- Focused on reducing clutter and increasing interpretability

## Skills Demonstrated ✨
- Data visualization and visual redesign
- Analytical storytelling
- Translating historical data into modern visual formats
- Applying design principles (clarity, contrast, hierarchy)

## Tools & Technologies 🛠️
- Python
- Jupyter Notebook
- matplotlib / pandas

## Outcome 🎯
The redesigned visualization clearly highlights the spatial clustering of cholera deaths around the Broad Street pump, reinforcing John Snow’s original epidemiological insight through improved visual communication.
