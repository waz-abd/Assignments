# Stockfolio: Portfolio Management Simplified 📈
Portfolio Management, Simplified

Stockfolio is a multi-platform portfolio management application that allows users to track and analyze stocks, bonds, real estate, and cryptocurrencies in one unified dashboard.

## Features 🚀
- Track multiple asset classes in one place
- Real-time market data and price updates
- Portfolio performance and asset allocation visualizations
- Watchlist management with alerts
- Secure cloud-based access across web and mobile

## Problem 🚨
Investors often rely on multiple apps or spreadsheets to track different investments, making it difficult to evaluate total net worth and risk exposure. Stockfolio solves this problem by centralizing all assets into a single platform.

## Tech Stack 🛠️
- Cloud: Google Cloud Platform
- Backend: Node.js
- Database: MariaDB
- Server: Ubuntu Linux (Compute Engine)
- Web Server: Apache
- Data Sources: External APIs for stock and cryptocurrency data

## Monetization 💵
- Free Tier: Basic tracking, limited assets, ads
- Premium Tier: Unlimited assets, real-time updates, advanced analytics, exportable reports, no ads
